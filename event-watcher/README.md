# EventWatcher

[![event-watcher | Upload to CurseForge](https://github.com/furiousteabag/wow-event-logger/actions/workflows/event-watcher-deploy.yml/badge.svg)](https://github.com/furiousteabag/wow-event-logger/actions/workflows/event-watcher-deploy.yml)

EventWatcher is a World of Warcraft Classic addon that monitors information about selected guild members and dumps it to file.

It is a part of the program that lets you monitor your friend's character progression in WoW in channels like Telegram, and by itself, the addon is not very useful. Full setup instructions are on the [project page](https://github.com/furiousteabag/wow-event-logger).

![Image](https://github.com/user-attachments/assets/fc41dc84-21d4-420c-98e8-d7139d07f77f)

## Installation

Grab an addon from [CurseForge](https://www.curseforge.com/wow/addons/eventwatcher).

## Usage

All commands are prefixed with `ew` (**E**vent**W**atcher).

### /ewadd \<name\>

Add character to the watchlist

### /ewremove \<name\>

Remove character from the watchlist

### /ewlist

List all watched characters

## Trivia

Install [Deathlog](https://www.curseforge.com/wow/addons/deathlog) addon if you want death information to be written as well.

Install [ChatLinkIcons](https://www.curseforge.com/wow/addons/chatlinkicons) addon if you want to have the same race & class icons prefix in chat like on screenshot
